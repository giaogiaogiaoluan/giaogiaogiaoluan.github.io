# lewisluan · 个人作品集

在线主页：https://giaogiaogiaoluan.github.io/

原生 HTML、CSS、JavaScript 静态网站，由 GitHub Pages 从 `main` 分支的根目录发布。没有构建依赖、统计脚本、表单或后端服务。

## 本地预览

在此目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，打开 http://127.0.0.1:8765 。

## 内容维护

- `index.html`：个人介绍、项目描述、链接与搜索分享信息。
- `styles.css`：配色、排版、手机布局和深色模式。
- `script.js`：主题切换与页脚年份。
- `favicon.svg`：站点图标。
- `.nojekyll`：直接发布静态文件。

修改并提交到 `main` 后，GitHub Pages 会自动更新。项目配图为原创概念排版，并非应用截图或真实数据。
